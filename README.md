## 🚀 What This Platform Does

**For Customers**
- Fund wallet via Korapay
- Buy social media services (Global + Nigeria catalogues)
- Track orders, transactions, and wallet history
- Redeem vouchers
- Earn referral commissions
- Request custom websites (Landing Page, Business Website, E-commerce Store, Security Audit, Security Fix)
- Pay deposits and balances from wallet
- Track project progress with milestones and timelines

**For Admins**
- Full admin panel: orders, users, services, shop, analytics, transactions, vouchers, website requests
- Quote website requests with custom deposit percentages
- Send automated emails to customers
- Bulk order actions

**For Moderators**
- Dedicated activity panel
- Real-time fraud detection (20+ flags)
- Block / unblock users with reasons
- View wallet timelines for every user
